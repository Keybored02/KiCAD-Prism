# Getting Started

## Local Preview

Install the documentation dependencies and run the MkDocs dev server from the repository root:

```bash
pip install mkdocs-material
mkdocs serve
```

## Writing Pages

- Put wiki pages in `docs/`
- Use Markdown headings for sections
- Add pages to `mkdocs.yml` so they appear in navigation

## GitHub Pages

The repository includes a GitHub Actions workflow that builds the site and publishes it to GitHub Pages.
